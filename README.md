# Python Learning Journey

This repository traces my Python practice from core language concepts to working with files, HTTP APIs, SQLite, and NumPy. It preserves exercises from two stages of my learning.

## 1. Python fundamentals and file handling

In [Learning Python well](learning-python-well/), I practiced organizing code into classes and modules, handling exceptions, and working with text and JSON files.

- [Calculator](learning-python-well/calculator.py) and [entry point](learning-python-well/main.py) show how I imported and used a class from a separate module.
- [Exception handling](learning-python-well/exception_handling.py) collects my practice with handling errors.
- [JSON exercises](learning-python-well/Json_test.py) document my practice with structured data.
- [Student records](learning-python-well/students.py) and [validation](learning-python-well/validate_students.py) show how I modeled records and organized validation in a separate module.

## 2. APIs, databases, and numerical computing

In [Python Environment](python-environment/), I moved on to HTTP requests, querying local databases, and working with numerical data.

- [HTTP request exercise](python-environment/api_test.py) passes query parameters and handles timeouts and request errors.
- [SQLite exercises](python-environment/database_understanding.py) filter student records and use parameterized queries to look up a student and update their course.
- [NumPy practice](python-environment/numpy_tutorial.py) covers arrays, summary statistics, and replacing placeholder values with a median. This was part of building my foundation for machine learning.
